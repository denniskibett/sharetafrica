# Sharet Africa brand (local copy)

Copied from the brand canvas artifact (https://claude.ai/artifact/RqcUnYaoAPVrKovLtoYqUQ) on 31 Oct 2026 so it can be opened and edited with the code.

- `index.html`: open in a browser for a list of every board, grouped by canvas page.
- `project/*.dc.html`: the boards. Each one is plain HTML; edit the markup directly.
- `project/canvas.json`: board titles, pages and positions on the canvas.
- `assets/`: logos and graphics the boards use (originally the canvas's `/_blob/…` files).

**The approved identity is "Two Lanes"**: pages *4 · Sharet Africa brand* and *7 · Social media identity*.
Page *1 · Logo explorations* holds the directions that were not chosen.

The production logo files the website uses are in `public/images/brand/`. When a logo changes here,
export it to that folder as well (same file names) so the site, emails and favicon pick it up.
